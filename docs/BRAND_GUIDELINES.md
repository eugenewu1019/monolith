# MONOLITH 品牌識別計劃書 (Brand Identity Guidelines)

> **Geological Pastry Lab**  
> 地質甜點實驗室。質地與時間的交會。

---

## 1. 品牌核心 (Brand Core)

### 1.1 品牌理念 (Brand Philosophy)
**「味覺建築 (The Architecture of Taste)」**
MONOLITH 不僅僅是製作甜點，而是關於物質的解構與重組。我們將甜點視為「瞬時的建築」，它必須在物理空間中佇立，卻在味覺的時間軸上崩塌。

*   **關鍵字 (Keywords)**:
    *   **Structure (結構)**: 建築感、支撐、層次。
    *   **Texture (質地)**: 粗糙與光滑的對比、與地質紋理的共鳴。
    *   **Time (時間)**: 瞬時性、消逝、記憶。

### 1.2 敘事語調 (Tone of Voice)
*   **理智且詩意 (Intellectual & Poetic)**: 使用精準的物質名詞（如：結晶、張力、密度），結合感性的體驗描述。
*   **低調奢華 (Understated Luxury)**: 避免浮誇的形容詞，專注於本質的描述。
*   **雙語並行 (Bilingual)**: 以全球化的視野，提供中英對照的深度體驗。

## 2. 視覺識別系統 (Visual Identity System)

### 2.1 標誌設計 (Logo Design)
MONOLITH 的標誌採用極簡的字體設計（Logotype），象徵巨石的穩重與永恆。

*   **標準字 (Logotype)**:
    *   字體：基於 Serif (襯線體) 的定製字型。
    *   特徵：全大寫 (All Caps)，寬字距 (Wide Tracking)，強調水平延伸感。
    *   應用：通常與副標 "GEOLOGICAL PASTRY LAB" 搭配使用。

### 2.2 色彩計畫 (Color Palette)
品牌色彩靈感來自地質礦物與深夜的氛圍。以極致的黑與灰為基底，點綴象徵礦脈的金屬色。

| 色彩名稱 | 色碼 (Hex) | 應用說明 (Usage) |
| :--- | :--- | :--- |
| **Zodiac Black** | `#0a0a0a` | **背景主色**。深邃、無限，象徵宇宙與黑夜。 |
| **Zodiac Charcoal** | `#1a1a1a`| **次要背景/卡片**。稍微提亮，用於區分層次與容器。 |
| **Zodiac Gold** | `#a08060` | **品牌主色 (Primary)**。低飽和度的古銅金，用於強調重點、線條與互動反饋。 |
| **Zodiac Concrete** | `#2a2a2a` | **輔助色/邊框**。如岩石般的深灰色，用於分割線與次要文字。 |
| **Zodiac White** | `#ededed` | **文字主色**。非純白，帶有微溫的灰白，減少螢幕閱讀的刺眼感。 |
| **Moonlight** | `#ffffff` (20% Opacity) | **光暈/微光**。用於玻璃擬態 (Glassmorphism) 與互動發光效果。 |

### 2.3 標準字體 (Typography)
字體選用強調「對比」，將現代無襯線體的機能性與古典襯線體的優雅結合。

| 類別 (Category) | 字體名稱 (Font Family) | 應用範圍 (Usage) |
| :--- | :--- | :--- |
| **Display (En)** | **Cormorant Garamond** | 大標題、數字、Logo、強調性英文短句。 |
| **Body (En)** | **Inter** | 功能性文字、介面按鈕、說明標籤。 |
| **Display/Body (Zh)** | **Noto Serif TC (思源宋體)** | 所有中文標題與內文。宋體的筆畫呼應了甜點的細膩層次。 |

## 3. 設計應用規範 (Design Application)

### 3.1 網頁介面 (Web UI)
MONOLITH 的數位體驗應如同漫步於深夜的藝廊。

*   **沈浸式黑暗 (Immersive Dark Mode)**: 始終維持深色模式，不僅是為了美學，更是為了讓「甜點」成為視覺中唯一的光源。
*   **微互動 (Micro-Interactions)**: 游標的磁吸效果、卡片的懸浮微光、滾動時的視差，模擬物質在重力下的物理反應。
*   **排版留白 (Whitespace)**: 大量的負空間（Negative Space），營造呼吸感與高級感。

### 3.2 影像風格 (Photography Style)
*   **Low Key (低調)**: 背景全黑或深灰，透過戲劇性的側光（Chiaroscuro）強調甜點的輪廓與質地。
*   **Macro (微距)**: 特寫甜點的斷面、氣孔、淋面的光澤，展現「地質」般的細節。
*   **無人像 (Product-First)**: 畫面專注於產品本身，除了主廚的手部操作外，避免過多人物干擾。

### 3.3 文案落款 (Signature)
在所有正式文件或包裝的結尾，統一使用以下落款格式：

> **MONOLITH**  
> *Taipei*
